# vk-graph

3D-визуализация графа друзей ВКонтакте: FastAPI-бэкенд, интерактивный фронт, экспорт в JSON и GraphML

**Стек:** `Python 3.12` · `FastAPI` · `Pydantic v2` · `VK API` · `Three.js` · `Docker`

## Чем показателен

Профиль junior Python backend в чистом виде: асинхронный REST, работа с внешним API и его лимитами, разделение слоёв, свой фронт поверх.

## Что внутри

- **Слоистый бэкенд** — `api` / `core` / `schemas` разведены: роутер не знает про VK, клиент не знает про HTTP, схемы не знают ни про то, ни про другое
- **Два режима обхода** — только друзья или друзья друзей; второй режим упирается в лимиты VK API, и это решается батчингом в `vk_client`
- **Три формата выгрузки** — JSON для своего фронта, GraphML для Gephi, PNG для отчёта
- **Токен только из окружения** — `.env.example` пустой, в коде хардкода нет

## Что не попало в публичную версию

**Папка `exports/` в зеркало не входит.** В приватном ядре там лежат реальные выгрузки: 756 узлов с именами, идентификаторами и ссылками на фотографии живых людей и 11 448 связей между ними. Это персональные данные третьих лиц, и в публичной репе им места нет ни в каком виде. Формат выгрузок виден по коду `backend/core/exporter.py`.

## Как это опубликовано

Публичное зеркало приватного ядра. Ядро живёт в закрытом репозитории,
сюда переносится **только то, что явно внесено в белый список** — не «всё, кроме
исключений»: чёрные списки протекают, и одного забытого шаблона хватает,
чтобы уехало лишнее. Публикация идёт скриптом, перед пушем прогоняется
секрет-сканер. Решение и его основания — ADR-009 в системе репозиториев автора.
